# `irodori`

![Coded With AI](https://img.shields.io/badge/coded-with%20ai-black?style=flat-square)

> Painting my ordinary days

`irodori` is a local-first diary app for organizing notebooks and writing Markdown entries.  
**[Visit the app](https://nenw.dev/irodori)**

## Features

- Organize your writing in separate notebooks
- Write diary entries with Markdown
- Add tags to keep moments easy to find later
- Decorate entries with stickers
- Include cover images and photos inside your entries

## Database
You can use your own cloud as a backend via S3 or WebDAV APIs.  
Built on [clxdb](https://github.com/HelloWorld017/clxdb)
